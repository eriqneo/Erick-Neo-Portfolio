# Erick Neo — brand kit

Dot-matrix "EN" monogram. Files live in `public/brand/`, generated from `src/data/logo-grid.json` by `scripts/brand/generate.py` — edit the grid, re-run, never hand-edit these files.

| File | Use |
|---|---|
| `erick-neo-lockup-on-dark.svg` / `.png` | Primary lockup on dark surfaces (#12110F) |
| `erick-neo-lockup-on-light.svg` / `.png` | Primary lockup on light surfaces (#F4F1EA) |
| `erick-neo-lockup-mono-black.svg` / `-white.svg` | Single-colour print, embossing, partner logos |
| `erick-neo-mark-*.svg` | Monogram only: avatars, social, stickers |

Rules
- Accent dot: #C24D64 on dark, #7D1D32 on light. Never use the status green (#5FBF73).
- Clear space: at least the width of the E's two-dot stem on every side.
- Minimum size: lockup 120px wide; mark 24px tall. Below that use the favicon cut (`/favicon.svg`), where every dot becomes a pixel.
- Wordmark: Familjen Grotesk SemiBold, −1% tracking, outlined in the SVGs (no font needed).
- Don't recolour individual dots, add gradients/shadows, or change the grid.
